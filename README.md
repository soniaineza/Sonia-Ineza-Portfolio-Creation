# Sonia Ineza portfolio

React, Vite, Tailwind and React Router.

```bash
npm install
npm run dev      # local development
npm run build    # production build into dist/
npm run lint
```

Content lives in `src/content/` (`projects.ts`, `profile.ts`). Images go in `public/work/`.

Deploys to Vercel; `vercel.json` rewrites routes to `index.html`.
